점검 범위

Python 웹훅 핸들러의 지원 패턴을 점검합니다. 탐지되지 않았다는 결과가 전체 코드의 안전을 보증하지는 않습니다.

정적 분석 · 5개 규칙

WHSEC-001 서명 검증 및 실패 거부 패턴 확인
WHSEC-002 서명의 일반 비교 사용
WHSEC-003 레거시 HMAC 알고리즘 사용
WHSEC-004 시간값의 만료 검증 누락
WHSEC-005 외부 검증 함수 내부 결함

동적 분석 · 3개 시나리오

다운그레이드·서명 정책 / 재전송 / 타입 혼동·입력 정책을 시험합니다. 플랫폼에 따라 적용 가능한 시험이 다릅니다. 타입 시험의 수락만으로 인증 우회를 의미하지 않습니다.

관측 수준

Tier 1은 상태 조회를 통한 전후 비교, Tier 2는 HTTP 응답 기반 관측입니다. 정상 기준 요청이 실패하거나 처리 증거가 부족하면 취약을 확정하지 않습니다.

플랫폼 범위

GitHub·Stripe·Slack·토스페이먼츠·PortOne V2의 지원 서명 형식을 사용합니다. 토스 서명 시험은 지급대행·셀러 이벤트 범위이며, 실제 이벤트 스키마와 업무 연동은 대상에 맞춰야 합니다.

로컬 실행 가이드

app.py가 있는 프로젝트 폴더에서 시작하세요.

1. 의존성 설치

pip install -r requirements.txt

2. 웹훅 수신 서버 실행

uvicorn samples.shop_server:app --port 8000

3. 다른 터미널에서 분석 서버 실행

uvicorn app:app --port 8001

브라우저에서 http://127.0.0.1:8001을 열고 ‘시연 설정’을 누르세요. 이후 samples/shop_server.py를 선택하면 됩니다.

정적 분석만 사용

‘정적 분석만’을 선택하면 수신 서버와 시크릿 없이 코드 검사를 진행할 수 있습니다.
